## 二、VS Code 关键设置

`C:\Users\LENOVO\AppData\Roaming\Code\User\settings.json`：

```json
{
  "verilog.linting.linter": "iverilog",
  "verilog.ctags.enabled": true,
  "verilog.ctags.path": "D:\\tools\\ctags\\ctags.exe"
}
```

**重要：`verilog.linting.path` 必须留空。** 插件内部会拼 `path.join(该值, "iverilog")`，
一旦填成目录 `D:\iverilog\bin`，拼出来就是没有 `.exe` 后缀的路径，Doctor 会报
`iverilog binary: D:\iverilog\bin\iverilog not found`。留空后插件会自己从 PATH 找。

## 三、踩过的坑（按血泪程度排序）

1. **`iverilog -v` 不是查版本**，是 verbose 模式，会把库路径全部打印出来，看起来像"卡死"。
   查版本要用大写 **`-V`**。（`gtkwave -v` 才是版本，两个命令不一样，很坑。）
2. **命令行有当前目录的概念**。在 `C:\Users\LENOVO` 下敲 `gtkwave wave.vcd` 必然找不到文件，
   必须先 `cd /d D:\fpga-portfolio\projects\01_led_blink`。
3. **`.bat` 双击没反应多半是安全软件静默拦截**。改用命令行手动三步跑，最可靠。
4. **GTKWave 打开是空白窗**：要在左侧 SST 里点进 `tb_led_blink` → `u_led_blink`，
   再双击 `clk/rst_n/led/cnt` 把信号加进去，最后点 Zoom Fit。
5. **linter 只在打开文件和保存文件时跑**。改完代码没红线是正常的，按 `Ctrl+S` 才会触发；
   编辑器标签上的 `●` 就是"未保存"标记。
6. **Vivado 2020.2 统一安装器**：这个镜像是单产品镜像（日志里 `Hide Package Panel: true`），
   Vitis / Vivado / Vitis HLS 三项是绑死的，点不动也拆不开。
   `60.87 GB` 是地板价——取消勾选 MATLAB Add-On 和 Alveo 后就已经到下限了。
   接受它，别再纠结"能不能再小点"。
7. **安装目的地根目录要填 `E:\Xilinx`**（安装器会自己补子目录），
   我之前填 `...\Vivado\2020.2` 导致目录嵌套套了两层。实际落成的是 **`E:\Xilink`**（少一个 x）。
8. **Win11 右键没有 7-Zip 菜单**：不是没装，是 Win11 把经典右键菜单折叠了。
   用"显示更多选项"或 `Shift + 右键`，也可以导入 `D:\FPGA_Tools\Win11恢复经典右键菜单.reg`。
9. **CH340 驱动**：`D:\串口驱动.rar` 存在 ≠ 装进系统了。外层 `SETUP.EXE` 只是自解压，
   真正的安装程序是 **`DRVSETUP64.exe`，必须右键"以管理员身份运行"**。
10. **安装完成后的右下角弹窗 "Vivado 2026.1.1 Available" 是广告**（Xilinx Information Center，
    简称 XIC），**不要点**，不要下载。可在任务管理器"启动"页把它禁用。
    左侧 `Installation completed successfully` 才是真的装完了。
